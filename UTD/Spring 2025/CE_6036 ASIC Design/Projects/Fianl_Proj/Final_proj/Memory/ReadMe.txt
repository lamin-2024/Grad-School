The memories for storing R, coefficients and input data are named as "R_MEM.v", "CO_MEM.v", "DATA_MEM.v" respectively. The original generated Verilog modules trigger errors during simulation so I made a few modification. The memories consists of several SRAM blocks from the SRAM collection of Hammer framework. This SRAM collection is constructed using ASAP7, the 7nm library. The GDS, LEF and LIB files of the SRAM blocks are in respective directory.
